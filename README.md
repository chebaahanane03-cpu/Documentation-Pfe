# Novalya – Site Web de Gestion de Stock des Bijoux

## Description
Novalya est une application web développée pour gérer les bijoux, les catégories et le stock.

## Fonctionnalités
- Ajouter un produit
- Modifier un produit
- Supprimer un produit
- Afficher les produits
- Gérer le stock
- Gérer les catégories

## Technologies utilisées
- HTML
- CSS
- JavaScript
- PHP
- PDO
- MySQL
- XAMPP

## Structure du projet

bijoux_project/
│── db.php
│── functions.php
│── index.php
│── add.php
│── edit.php
│── delete.php
│── style.css

## Installation

1. Télécharger le projet
2. Importer la base SQL
3. Copier le dossier dans htdocs
4. Lancer XAMPP
5. Ouvrir localhost
